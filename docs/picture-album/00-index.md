> 本资料包是「云端图库」项目引入**相册（Album）**能力的完整背景与规格来源。  
> 阅读顺序建议：`00-index → 01-background → 02-requirements → 03-api-contract → 04-engineering-guide → 05-change-log`。  
> **重要**：本资料包跨越多次产品/技术评审，包含若干**已被推翻的历史方案**。当任意两处描述冲突时，一律以 `05-change-log.md` 中**日期最新且标记为「最终决议（FINAL）」**的条目为准；凡标注「已废弃（DEPRECATED）」「仅历史参考」的方案**不得实现**。

## 名词表（贯穿全篇）

- **图片（Picture）**：已存在的实体，对应后端 `Picture` 与磁盘上的图片文件。相册功能**不改变**图片的存储方式。
- **相册（Album）**：图片的逻辑集合。一个相册包含 0..N 张图片。
- **成员关系（Membership）**：图片与相册之间的从属关系。**一张图片可同时属于多个相册**。
- **封面（Cover）**：相册对外展示的代表图，必须是该相册的成员之一。
- **图库（Library）**：全部图片的总集合，即现有首页图片墙。相册是图库之上的一层视图，**不是**图片的物理归属地。

## 阅读提示

- 术语一致性很重要：下文所有「移出相册（remove from album）」都**只解除成员关系**，绝不删除图片本身；「删除图片（delete picture）」才会动到文件与图片记录。二者在多处被反复强调，请勿混淆。
- 端口、技术栈、分层等工程纪律集中在 `04-engineering-guide.md`，但其**约束效力覆盖所有轮次的所有改动**。
